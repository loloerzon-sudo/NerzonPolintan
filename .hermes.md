## Deploy reality (READ THIS BEFORE ANY PUSH)
- The **live site is the React app**, *not* the static HTML files at the repo root.
- `.github/workflows/deploy.yml` runs on every push to `main`/`master`: `npm ci` in `react-app/`, `npm run build`, then uploads **only `react-app/dist`** to Pages.
- **=> Every `git push` to `main` triggers a live deploy. NEVER push without explicit user approval.** (The `push.bat` helper does a straight `git push`; treat it as publish-to-prod.)
- SPA deep-links work on GitHub Pages via the `?p=...` rewrite trick: `react-app/public/404.html` (fallback) + the decoder script in `react-app/index.html`. Vite `base` is **unset** (defaults to `/`) — the app lives at the domain root, not a subpath.
